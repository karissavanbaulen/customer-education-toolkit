# Customer Education Toolkit

The templates I've actually used to run customer education, docs and support teams. They're cleaned up so you can copy them, but each one started as a real doc for a real team.

I'm [Karissa Van Baulen](https://github.com/karissavanbaulen). I've built education and knowledgebase teams at Hotjar and Pallon, and I write [What the FAQ?!](https://what-the-faq.kit.com/).

## What's in here

| Template | Use it when |
| --- | --- |
| [OKRs for education](templates/okrs.md) | You need education goals that leadership reads as revenue goals |
| [Business case](templates/business-case.md) | You want budget, tooling or headcount |

More templates are on the way: career ladders, onboarding plans, hiring tasks, 1:1s, AI support agent audits and course style guides. Watch the repo or check the [changelog](CHANGELOG.md) to see when they land.

Every template starts with a short "Where I used this" note, so you know what it was built for and what happened.

## How to use them

1. Copy the file into your own docs tool (Notion, Google Docs, Confluence, a repo, whatever).
2. Replace everything in `{curly braces}`.
3. Delete the parts that don't fit your team. They're starting points, not rules.
